# Framework figure

`framework.pdf` (vector, for LaTeX), `framework.png` (4000×1800) and `framework.svg`
are generated by `tools/figures/make_framework_figure.py`. Only thumbnails of images
already in this repository are embedded: dataset elements and symbols, and the three
archived “7.5 results” triplets. No scores are drawn in the figure.

```bash
git lfs pull --include="KUSHULAN_dataset/**,data/整理的数据-常用_副本/库淑兰-data-处理后/Pattern_symbols/**" --exclude=""
python tools/figures/make_framework_figure.py
```

Needs ImageMagick (`magick`) for thumbnails and Chrome/Edge for PDF/PNG export;
`--svg-only` skips the export.

## LaTeX

```latex
\begin{figure*}[t]
  \centering
  \includegraphics[width=\textwidth]{figures/framework.pdf}
  \caption{\textbf{Overview.}
  (a) Ku Shulan papercuts are curated into 282 records (179 elements in six categories,
  103 symbols in 21 classes). Each record pairs an image with a structured caption whose
  terms are split into content tokens $y_c$ and style/symbol tokens $y_s$; exact and
  near-duplicates are grouped ($g$) before splitting.
  (b) On a frozen SDXL, LoRA factors ($r{=}64$) are trained only in
  \texttt{up\_blocks.0}: \texttt{attentions.0} captures content and
  \texttt{attentions.1} captures style.
  (c) At inference, the content block of one run and the style block of another are
  scaled by $\alpha_c,\alpha_s$ and merged, so structure and appearance can be
  recombined freely.
  (d) Outputs are scored for structure, style, text alignment and expert judgement.
  Pixel-aligned structure metrics are reported against a mismatched-content control.}
  \label{fig:framework}
\end{figure*}
```

中文图注：**方法总览。**(a) 将库淑兰剪纸整理为 282 条记录（6 类 179 个元素，21 类 103 个纹样），每条记录包含图像与结构化描述，描述词分为内容词 $y_c$ 与风格/符号词 $y_s$，并在划分数据集前将重复与近重复图像归为同组 $g$。(b) 冻结 SDXL，仅在 `up_blocks.0` 训练 rank 64 的 LoRA：`attentions.0` 学习内容，`attentions.1` 学习风格。(c) 推理时取一次实验的内容块与另一次实验的风格块，按 $\alpha_c,\alpha_s$ 缩放后合并，实现结构与外观的自由组合。(d) 从结构、风格、文本一致性和专家评价四方面评估；像素对齐的结构指标同时报告错配对照。
