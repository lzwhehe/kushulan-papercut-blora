参考流程图写有 2,008 件原作；当前原作 ZIP 中检测到 1,153 个图像条目。可能存在采集版本差异；在补充记录前不将 2,008 写作已复核规模。

## 标注与使用

提示词保留在原始 DOCX 中，其中包含 `file_name` / `text` 形式的记录。图像存在双重扩展名（例如 `1.jpg.jpg`）与特殊命名（例如 `7..jpg.jpg`）。直接训练前必须核对文件名映射，不能假设文档中的 `1.jpg` 已自动匹配到全部数据版本。

处理流程文档属于原始研究资料，其关于设备、色差控制、图像格式等文字是来源陈述。本次未执行色差测量、分辨率认证或专家复核，因此不将 ΔE ≤ 2.5 等写作已验证结果。

本仓库不自动分配 train/validation/test：备份或近重复版本容易跨集合泄漏，应按原作来源分组，再制定划分。

## 许可范围

代码许可证不覆盖原始剪纸作品、数据、提示词文档和已有模型。原始资料中未找到独立数据许可证；本仓库不代替原权利人授予重新分发、商业使用或衍生使用许可。新增工具和第三方代码的许可分别见根目录与 `vendor/B-LoRA/`。
